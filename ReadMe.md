## Description 📝
> Level editor and importer for the game [Vector](https://store.steampowered.com/app/248970), using Unity.

Released due to original version's 17th February 2025 update containing new object system, which made unification of the both versions impossible.

## Requirements 📥
- [Vector](https://store.steampowered.com/app/248970) ([Steam](https://store.steampowered.com), v4.5.0)
- Unity Editor [2020.3.35f1 (revision 18e4db7a9996)](https://download.unity3d.com/download_unity/18e4db7a9996/Windows64EditorInstaller/UnitySetup64-2020.3.35f1.exe) at the [official Unity Website](https://unity3d.com/get-unity/download/archive)
- [Unity Hub](https://unity.com/unity-hub)

## Installation 🖥️
01. Download the [Vectorier Unity Editor project](../../archive/refs/heads/main.zip)
   - Extract the ZIP file
   - Open the project in Unity Hub
02. Head to `Project Settings → Vectorier → General`
03. Adjust `Paths → Game Directory` so it contains `Vector.exe`

## Features
> Compared to the forked repo, based on the latest commit of this repository.

01. [One true brace](https://wikipedia.org/wiki/Indentation_style#One_True_Brace) indentation style
02. Modular code
03. Native hunter mode support
04. 3rd model placeholder in map building component
05. Level title support
06. Level thumbnail support
07. Transparent level interface toggle in map building component
08. Map optimization flag in map building component
09. Model color support
10. Track coin reward support
11. Individual custom model properties per mode
12. Scene validation
13. Project credits
14. Track XML validation window
15. Node sorting
16. Relative `<Object>` positioning flag
17. Elements precision configuration
18. Notifications about updates inside the editor (can be switched off completely)
19. `Moves_new.xml` manager
20. Map `<Sets>` manager
21. `sound.dz` manager
22. Dynamic `.dz` archives compilation
23. New sound assets
24. New texture assets
25. New animations assets
26. New skins assets
27. `.lua` script for [Cheat Engine](https://www.cheatengine.org) that could increase samplerate of sound files to CD quality
28. Area Properties
29. Target write mode
30. Built-in `VectorierUtils`
31. Rotation + skew support
32. Multiple dynamic move interval transformations components support
